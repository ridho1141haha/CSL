## 2024-10-23 - Prevent full re-renders from fractional state updates
**Learning:** Selecting rapidly changing state directly in a root component causes the entire component and its children to re-render on every tiny update. In this case, `focus` regenerating fractionally every frame in `Player.tsx` was causing the entire `Hud` component to re-render constantly. Also, using inline continuous checks like `Date.now() - lastHit < 400` only work if the component is being continuously re-rendered.
**Action:** Isolate rapidly changing state into tiny, `React.memo`-wrapped child components (like `PlayerVitals` and `PlayerCombatPanel`) to keep re-renders local to the elements that actually need to change. When fixing these re-renders, make sure to replace continuous time checks with effect-driven local state.
